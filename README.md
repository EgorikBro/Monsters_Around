# Monsters Around

**Monsters Around** — это проект в жанре **Roguelike** и **Dungeon Crawler**, представляющий собой пошаговую игру об исследовании подземелий. Проект разрабатывается для платформы **PC** на языке **C#** с использованием фреймворка **MonoGame**.

## 🎮 Основная концепция
Игрок берет на себя роль исследователя процедурно генерируемого подземелья, состоящего из комнат и разветвленных коридоров.
* **Цель игры:** Преодолеть как можно больше этажей.
* **Активности:** Сражения с монстрами и сбор полезных предметов.
* **Сложность:** В игре реализована механика перманентной смерти — при обнулении здоровья прогресс теряется навсегда.

## ⚔️ Игровые механики
* **Пошаговая система:** Мир и противники реагируют только на действия игрока. Один шаг персонажа равен одному ходу всех существ на карте.
* **Процедурная генерация:** Уровни создаются алгоритмически при каждом новом запуске. Алгоритм на основе прямоугольников и путей автоматически соединяет комнаты и расставляет предметы.
* **Система боя «Бамп»:** Атака происходит при попытке игрока шагнуть в клетку, занятую противником. Урон рассчитывается исходя из текущих характеристик атаки и HP.
* **Ресурсы:** Игрок должен следить за полоской здоровья (HP), используя найденные аптечки и бонусы к урону.

## 🛠 Технические особенности
* **Графика:** 2D, вид сверху, использование тайловой сетки и готовых ассетов.
* **Данные:** Карта хранится и обрабатывается в виде двумерного массива.
* **ИИ врагов:** Простой алгоритм поиска пути для преследования игрока по кратчайшей траектории.
* **Архитектура:** Система состояний (State Machine) для переключения между Меню, Геймплеем и Экраном смерти.
* **Интерфейс:** Реализован UI для отображения жизненно важных показателей и номера текущего этажа.

## ⌨️ Управление
* **WASD / Стрелки:** Передвижение по сетке и инициирование атак.
* **Space (Пробел):** Пропуск хода (ожидание).
* **I:** Использование предметов из инвентаря.
